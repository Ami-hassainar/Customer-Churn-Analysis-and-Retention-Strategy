# Customer-Churn-Analysis-and-Retention-Strategy

## 📊 Project Overview

Developed a customer churn analysis project to identify key factors influencing customer retention. Performed data analysis using Python and SQL, and built an interactive Power BI dashboard to visualize churn patterns and provide actionable business insights. The goal is to uncover actionable insights that help businesses reduce churn and improve customer satisfaction.

---

## 🧰 Tools & Technologies

* Python (Pandas, Matplotlib)
* SQL (MySQL Workbench)
* Power BI
* Excel

---

## 🔍 Data Analysis Process

### 1. Data Cleaning

* Handled missing values
* Verified data types
* Cleaned dataset using Excel

### 2. Exploratory Data Analysis (Python)

* Analyzed churn distribution
* Identified top churn reasons
* Studied patterns across contract type, tenure, and services

### 3. SQL Analysis

* Calculated churn rate
* Extracted top churn drivers
* Performed segmentation queries

### 4. Dashboard Development (Power BI)

#### 📄 Page 1: Retained vs Churned Analysis

* Customer distribution
* Contract type comparison
* Service usage patterns

#### 📄 Page 2: Senior vs Non-Senior Analysis

* Churn rate comparison
* Tenure and contract insights
* Service-based churn patterns

#### 📄 Page 3: Insights & Recommendations

* Top churn reasons
* Business recommendations

## 🔥 Key Insights

* Month-to-month contracts have the highest churn rate
* Poor customer support is a major churn driver
* Senior customers have a higher churn probability
* Competitor offers significantly influence churn

---

## 💡 Recommendations

* Improve customer support services
* Offer long-term contract incentives
* Enhance competitive pricing and offers
* Focus on onboarding new customers

---

## 📌 Conclusion

This project demonstrates how data analysis and visualization can be used to identify churn drivers and support data-driven decision-making.
